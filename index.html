Aviso por WhatsApp

Si lo dejas vacío, el botón "Enviar por WhatsApp" te deja elegir el chat o grupo al enviar.
Cómo funciona esto
  1. La clave de eBird ya viene incluida en este archivo, así que ni tú ni tu amigo necesitan escribirla.
  2. Elige región y filtro, y presiona "Guardar y actualizar".
  3. El sitio revisa eBird automáticamente mientras esta pestaña esté abierta.
  4. Cada avistamiento nuevo trae un botón para mandarlo por WhatsApp con un clic.
  5. Si cierras la pestaña, las revisiones se detienen — no hay envío automático en segundo plano, eso requeriría un servidor aparte.
Esta página guarda todos los datos (tu API key, tu lista vitalicia, tus preferencias) únicamente en el navegador de este dispositivo — nada se envía a un servidor externo salvo las consultas directas a la API pública de eBird. Si tú y tu compañero usan esto, cada uno lo hace desde su propio dispositivo con su propia información.
